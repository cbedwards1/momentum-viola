# Momentum in Systems

This repository contains an interactive Jupyter Notebook and Voilà application
for investigating momentum conservation in one-dimensional collisions.

## Learning purpose

Students can:

- Adjust the masses and initial velocities of two carts
- Predict both carts' final velocities
- Compare individual and total system momentum
- Explore elastic and inelastic collisions
- Compare momentum conservation with kinetic-energy changes
- Identify assumptions and limitations built into the model

## Application files

- `momentum_voila_sandbox.ipynb` — interactive application and underlying model
- `requirements.txt` — packages required by Binder and Voilà

## Instructional use

Students should make predictions before revealing the model results. The
application does not permanently store student responses. Students should
submit screenshots, calculations, and explanations through Padlet or the
course learning-management system.

## Model assumptions

- The system contains both carts
- External impulse during the collision is negligible
- Motion is one-dimensional
- Masses remain constant
- Friction before and after the collision is not modeled
- The coefficient of restitution describes the collision
